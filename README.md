# Optimus AI

A Copilot-like assistant for enterprise application support and operations, built on the GitHub Copilot SDK
with bring-your-own-key model access.

| Folder | What |
|---|---|
| [`harness/`](harness/) | Agent backend: sessions, streaming, ServiceNow and Dynatrace tools. See its README to run it. |
| [`console/`](console/) | React web console (UI only, mock data for now). See its README to run it. |
